### 我的減肥嘗試

23 年的生活一直在路上，也在減肥的路上，在健康的路上。

由於不良的生活習慣，六月份畢業時，我整個人顯的十分臃腫。

直到我的體重來到了 170 斤+，我才意識到問題的嚴重性。

辦了健身卡、堅持跑步、控制飲食、好好睡覺。四個月的時間，我減掉了大概 20 斤體重，身體也變得更加健康。

## 職業規劃

是的，畢業半年，我就辭掉了工作。為什麼要辭職呢？

其實並非一時衝動，更大程度上是因為我自己的職業規劃。

我目前在做的崗位是 Web 前端開發工程師，預計未來的很長一段時間仍是。而在一年前，我甚至都不瞭解 Web 開發（那時的我，只是對 Web 開發充滿興趣，複製貼上寫過一點程式碼而已）。

### 在蔚來的實習經歷

未曾顧及繁星，也許久未見夕陽......

![](https://files.guoqi.dev/images/202402191832280.webp)

那時的我是實打實的菜鳥（現在也是，emmm，比之前好點～）。

為了跟上大公司的"流水線"，我需要花更多的時間去研究程式碼。

那個春天裡，除了學習和工作以外，我幾乎沒有任何其他時間可以支配。

![](https://files.guoqi.dev/images/202402191833887.webp)

好在，我是真心喜歡這份工作。

也十分感謝這段經歷，讓我看清了未來的職業方向。

![](https://files.guoqi.dev/images/202402191834165.webp)

### 我喜歡做前端開發

我喜歡折騰，搞開發就是折騰，我喜歡這個行業。

疫情的時候，居家隔離，因為不想上網課，我便開始研究起了電腦。

返校後的 C 語言實驗課上，我領悟到了這個黑乎乎視窗的強大能力，擼起袖子，便準備好好研究一番～

![](https://files.guoqi.dev/images/202402191835333.webp)

終端太醜了，後來我想給程式加上圖形介面，於是便研究起 C#......

![](https://files.guoqi.dev/images/202402191836229.webp)

寫好的東西不能直接分享，打包後的執行檔案還需要安裝，甚至因為環境問題跑不起來。因為種種原因，我對桌面 GUI 開發完全失去了興趣。

接觸到 Web 開發是因為搭建個人部落格。從域名註冊，到網站部署，Web 專案的簡單易用、拿來即用，讓我欣喜若狂。

![](https://files.guoqi.dev/images/202402191836603.webp)

但......

![](https://files.guoqi.dev/images/202402191837945.webp)

### 為自己打工

在工作中，我們都有兩個老闆。

第一個老闆是你的上司。你按照要求，完成任務，付諸勞動，換取薪水......

第二個老闆則是你自己。你要成為怎樣的人，在工作中獲得什麼樣的成長，完成哪些的目標，是這個老闆對你的要求。

我其實還挺喜歡工作的，因為在工作中我可以收穫成長，也就是所謂的為自己打工。

量變引起質變，在工作中自我驅動、自我成長，進而實現自我突破、自我迭代，或許在未來的某一天，我們便可以擺脫第一個老闆，成為只為自己打工甚至不打工的人。
